# DB1 UART 控制器規格

版本 1.2。本文件描述虛構示範板 DB1 上的 UART 控制器（以下稱 UART0）。

## 1 概觀

UART0 是一個非同步串列收發器，位於記憶體位址 `0x4000_1000`，輸入時脈 `PCLK` 為 48 MHz。

- 支援鮑率 1200 到 921600。
- 資料位元固定 8 位元，可選同位元檢查，停止位元 1 或 2。
- 傳送與接收各有 16 層 FIFO。
- 一條中斷線，編號 IRQ 5。

## 2 訊框格式

閒置時 TX 線為高電位。每個訊框依序是：1 個起始位元（低電位）、8 個資料位元（LSB 先送）、可選的同位元、1 或 2 個停止位元（高電位）。

![UART 訊框時序：閒置高電位、起始位元、八個資料位元、停止位元](assets/uart-spec-001.png)

接收端在每個位元的中間點取樣，所以兩端鮑率誤差必須小於 2%。

## 3 暫存器

所有暫存器寬度 32 位元，未列出的位元保留，寫入時須為 0。

| 偏移 | 名稱 | 存取 | 說明 |
| --- | --- | --- | --- |
| 0x00 | DR | 讀寫 | 資料暫存器 |
| 0x04 | BRR | 讀寫 | 鮑率暫存器 |
| 0x08 | SR | 唯讀 | 狀態暫存器 |
| 0x0C | CR | 讀寫 | 控制暫存器 |

### 3.1 資料暫存器 DR

寫入低 8 位元會把一個位元組放進傳送 FIFO。讀取會從接收 FIFO 取出一個位元組。

### 3.2 鮑率暫存器 BRR

BRR 低 16 位元是除數。鮑率計算式：

```
baud = PCLK / (16 × BRR)
```

PCLK 為 48 MHz 時，115200 鮑率對應 BRR = 26（實際鮑率 115384，誤差 0.16%）。BRR 為 0 時 UART0 停止運作。修改 BRR 之前必須先清除 CR.EN。

### 3.3 狀態暫存器 SR

| 位元 | 名稱 | 說明 |
| --- | --- | --- |
| 0 | TXE | 傳送 FIFO 有空位 |
| 1 | RXNE | 接收 FIFO 有資料 |
| 2 | OVR | 接收溢位：FIFO 已滿時又收到資料，新資料被丟棄 |
| 3 | FE | 訊框錯誤：停止位元取樣到低電位，通常代表鮑率不符 |
| 4 | PE | 同位元錯誤 |

OVR、FE、PE 在讀取 SR 之後再讀取 DR 時清除。

### 3.4 控制暫存器 CR

| 位元 | 名稱 | 說明 |
| --- | --- | --- |
| 0 | EN | 啟用 UART0 |
| 1 | TXIE | 傳送 FIFO 低於門檻時產生中斷 |
| 2 | RXIE | 接收 FIFO 達到門檻時產生中斷 |
| 3 | PEN | 啟用同位元 |
| 4 | STP2 | 使用 2 個停止位元 |

## 4 FIFO 與中斷

傳送與接收 FIFO 各 16 層。接收門檻固定為 8 層：FIFO 內達到 8 個位元組時，若 CR.RXIE 為 1 則觸發 IRQ 5。另有接收逾時：FIFO 內有資料但連續 4 個字元時間沒有新資料時，同樣觸發中斷，避免資料卡在 FIFO。

中斷服務程式必須把接收 FIFO 讀到 SR.RXNE 為 0，否則中斷會立刻再次觸發。

## 5 初始化順序

1. 設定腳位多工，把 PA9、PA10 切到 UART0 功能。
2. 清除 CR.EN。
3. 寫入 BRR。
4. 設定 CR 的 PEN、STP2。
5. 需要中斷時設定 CR.RXIE，並在中斷控制器啟用 IRQ 5。
6. 設定 CR.EN。
